# Fraunces Display

Instance statique de Fraunces : `opsz=144`, `wght=400`, `SOFT=0`, `WONK=1`.
Produite avec fontTools déjà présent dans l’environnement ; aucune dépendance ajoutée au projet.

Source officielle : https://github.com/google/fonts/blob/main/ofl/fraunces/Fraunces%5BSOFT%2CWONK%2Copsz%2Cwght%5D.ttf
Licence SIL Open Font License : voir OFL.txt.

Le dessin optique 144 est utilisé pour les titres et les grands chiffres, sur toutes les plateformes. Inter Tight sert au corps et aux labels.
